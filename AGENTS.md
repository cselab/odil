# AGENTS.md

Guidance for coding agents working in this repository.

ODIL (Optimizing a Discrete Loss): solves forward and inverse PDE problems by
minimizing the sum of squared residuals of a finite-difference/finite-volume
discretization (plus data and regularization terms), with TensorFlow or JAX
autodiff. Package in `src/odil`, examples in `examples/`, tests in `tests/`.

## Commands

Setup: `uv sync --group dev --extra tensorflow --extra jax` (Python >= 3.12).

- `make fix`: `ruff check --fix` and `ruff format` (default target does the same).
- `make check`: lint and format check without changes (what CI runs).
- `make mypy`: mypy on `MYPY_TARGETS` in `Makefile` only (currently just
  `history.py`); CI runs it, so annotate fully any file added there.
- Ruff: line length 120, rules E/W/F/I, double quotes.

Tests are standalone scripts, not pytest (except `test_io.py`, run with
`unittest`):

- `make -C tests all_tf -j` (CI), `make -C tests all_jax -j`
- single test: `make -C tests test_domain_tf` or `test_domain_jax`
- by hand, in `tests/`: `ODIL_BACKEND=tf ODIL_DTYPE=float64 python3 test_domain.py`
- `test_newton_jax` is skipped (Newton is TF-only).

## Runtime configuration (environment variables, read in `runtime.py`)

- `ODIL_BACKEND=tf|jax`: default is TensorFlow if importable, else JAX.
- `ODIL_DTYPE=float32|float64`: default `float32`.
- `ODIL_JIT=1`: XLA compilation (`tf.function(jit_compile=...)` / `jax.jit`).
- `ODIL_MT=1`: allow multithreading (otherwise forced to one thread).
- `ODIL_WARN=1`: keep TF logs and Python warnings.
- `CUDA_VISIBLE_DEVICES`: empty or `-1` disables GPU (the default).

`odil.runtime` and `odil.plot` are lazily imported in `__init__.py`, so
importing `odil` does not load TF/JAX; the backend is chosen on first access
to `odil.runtime`.

## Architecture

- `backend.py`: `ModNumpy` (NumPy/JAX) and `ModTensorflow` wrap backends
  behind a NumPy-like interface. Library and user code use `mod.*` (e.g.
  `domain.mod`, `ctx.mod`), never `tf`/`jnp` directly; `mod.tf` / `mod.jax`
  are set to tell backends apart.
- `core.py`, the central module:
  - `Domain`: grid (`cshape` in cells), `points()`, `indices()`, `step()`,
    optional multigrid hierarchy; packs/unpacks `State` to flat arrays for
    optimizers.
  - `State` holds `fields`: `Field` (grid array with `loc`, cell- or
    node-centered per axis), `MultigridField` (sum of interpolated coarser
    levels), `Array` (free parameters), `NeuralNet`.
  - `Problem(operator, domain, extra, tracers)`: `operator(ctx)` returns a
    list of `(name, residual)` tuples (names unique); loss is the sum of
    `mean(residual**2)` (or `Context.Raw` values taken as is).
    `eval_loss_grad` has separate `_tf`/`_jax` implementations and caches
    the compiled function. `linearize` builds a sparse Jacobian for Newton.
  - `Context`: passed to the operator; `ctx.field(key, *shift)` returns the
    field shifted by grid offsets (stencils), `ctx.neural_net(key)`,
    `ctx.extra` (plain Python, e.g. args; changing it does not retrace),
    `ctx.tracers` (part of the jitted signature).
- `optimizer.py`: L-BFGS-B (SciPy), L-BFGS, Adam (TF and native), GD;
  `make_optimizer(name)`.
- `util.py`: driver used by examples and tests: `add_arguments(parser)`
  (common CLI options), `setup_outdir`, `make_callback` (logging, history
  `train.csv`, plots, checkpoints), `optimize(args, optname, problem, state,
  callback)` dispatching to Newton (`linsolver.py`) or gradient optimizers.
- `core_min.py`: backend-free `Domain` for postprocessing without TF/JAX.
- `io.py`: raw/XMF/VTK output.

## Examples

Each example is a CLI script built on `odil.util`; `run` scripts hold the
canonical parameter sets (`case=... ./run`). `README.md` files in
example directories that contain a `README.py` are generated by `README.py`
(do not edit by hand). Outputs go to `out_*` (gitignored). Rendered example
outputs live on the `gh-pages` branch; test/reference data on the `data`
branch (`make data`).
